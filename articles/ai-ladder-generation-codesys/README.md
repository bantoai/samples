# 生成AIにラダー回路を書かせてみた（タンク設備）

記事「生成AIにラダー回路を書かせてみた：タンク設備、試験11項目が全部通った（CODESYSで動作確認）」のサンプルです。
生成AI にプロンプトだけでタンク設備のラダー（CODESYS の PLCopen XML）を書かせ、取り込み・ビルド・模擬設備での試験（11項目）をしました。

| ファイル | 中身 |

## 動作環境

| 項目 | 内容 |
|---|---|
| CODESYS | V3.5 SP22 Patch 4（PC 上のソフト PLC で実行） |
| ラダーの表示 | LD2 エディタ |
| 生成AI | （記事の公開時に追記します） |
| 試験 | 自作の模擬設備（タンク）を OPC UA でソフト PLC につないで実施。模擬設備は今回は公開していません |

## 再現の手順

1. 生成AI の新しいチャットに `prompt.txt` を全部貼る。出力が途中で切れたら「続きを出して」と頼み、つないで1つのファイルにする
2. 返ってきた XML の前後に ``` が付いていたら消して、`.xml` で保存する
3. CODESYS で新しいプロジェクト（標準のプロジェクト）を作る
4. `Application` の下にグローバル変数リスト `GVL_IO` を作り、`gvl/GVL_IO.st` の中身を貼る
5. `Application` を選んでから、「PLCopenXML のインポート」で XML を取り込む
6. `PLC_PRG` が LD2 で開くことを確かめ、ビルドする

模擬設備がないので、試験（11項目）はそのままでは再現できません。I/O を手で操作して確かめる場合は、`results/test-results.md` の「操作」と「○ の条件」を使ってください。

## 注意

- この XML は実験の記録です。実機や実際の設備では、そのまま使わないでください
- 仕様に書いていない動き（各個モードの水位インターロックなど）は入っていません。詳しくは `results/test-results.md` の「気づいたこと」を見てください
